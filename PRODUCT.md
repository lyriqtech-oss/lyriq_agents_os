# Agent Center

Agent Center by Lyriq é um espaço para criar e configurar agentes de IA, conversar com eles, definir skills e permissões, montar automações com agentes e criar projetos no Code.

O fluxo principal começa pela identidade do agente: sua função, público, entregas, limites e modelo. O usuário pode depois testar o agente em chat, usá-lo em um fluxo e pedir ao Code que crie um projeto com prévia. A interface deve mostrar o estado real desses recursos e orientar a próxima ação quando algo ainda não foi configurado.

As telas centrais são Início, Chats, Meus Agentes, Automações, Agent Center Code e Configurações. A Home resume agentes e fluxos reais do workspace. Não apresentar métricas, integrações, execuções ou confirmações fictícias como se fossem dados operacionais.
