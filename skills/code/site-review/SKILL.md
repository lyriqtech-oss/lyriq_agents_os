# Revisão de site

Revise o resultado como página real, não como uma lista de recursos. Confira se o primeiro quadro comunica o assunto, se o título cabe sem colidir com o menu e se a composição tem um elemento memorável ligado ao pedido. Remova decoração repetitiva e texto sem função.

Inspecione a consistência entre IDs, âncoras, seletores CSS e eventos JavaScript. Verifique que SVG e seções são visíveis sem rolagem ou animação. Confira estados de hover e foco, contraste, leitura no celular, ausência de rolagem horizontal e comportamento com movimento reduzido.

Ao editar para corrigir uma falha, compare com o pedido original. Não retire navegação, seções ou controles funcionais para fazer a revisão passar.

Uma revisão deve apontar falhas concretas que podem ser corrigidas nos arquivos. Não declare que viu uma captura de tela ou testou interações se essas ações não ocorreram.
