# Direção de site

Identifique assunto, público, objetivo da página e conteúdo realmente disponível. Escolha uma ideia visual ligada ao assunto. Defina paleta com valores hexadecimais, escala tipográfica com fontes de sistema, composição do primeiro quadro e um único elemento marcante. Explique como a mesma composição funciona em 375px e 1200px.

Compare a proposta com padrões comuns de sites gerados. Se ela depender de um fundo creme com título serifado genérico, gradiente decorativo, três cartões iguais ou números inventados, mude a direção. Respeite uma preferência visual explícita do usuário.

O primeiro quadro deve mostrar título legível, conteúdo e elemento visual. Desenhos SVG precisam aparecer sem animação, rolagem ou JavaScript. Não use imagens, fontes ou bibliotecas remotas: a prévia do Code não carrega esses recursos.
