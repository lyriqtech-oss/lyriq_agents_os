# Construção de site

Entregue HTML interno ao body, CSS e JavaScript em arquivos separados. Use conteúdo específico ao pedido, hierarquia clara, ritmo entre seções e uma composição adequada ao assunto. Use CSS próprio e SVG inline quando necessário; mantenha o conteúdo principal visível antes de qualquer script.

Faça navegação para destinos existentes e controles que executam uma ação real. Não invente preço, depoimento, contato, número comercial ou confirmação de envio. Sem canal de contato fornecido, use um fechamento editorial sem formulário de contato.

Confira largura, quebra de títulos, navegação e margens em 375px e 1200px. Inclua foco visível e respeite movimento reduzido. Se algo não puder funcionar no ambiente de prévia, apresente como conteúdo informativo, sem botão falso.

No celular, coloque o título principal antes de uma ilustração alta. Mostre o título nos primeiros 300 pixels de conteúdo útil e mantenha-o completo no primeiro quadro de 667 pixels de altura. Se uma correção alterar o hero, preserve a navegação e todas as interações pedidas.
